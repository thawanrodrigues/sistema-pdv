# Regras de Negócio: Conecta Sistemas

## Domínio do Problema
O Conecta Sistemas é um software de Ponto de Venda (PDV) e Gestão Empresarial. 

## Regras Atuais (MVP)
1. **Identidade Visual:** A marca deve exibir o nome "CONECTA SISTEMAS" predominantemente em branco, remetendo a uma solução moderna e premium.
2. **Navegação:** O sistema deve ter uma barra superior com navegação para módulos principais:
   - Clientes
   - Produtos
   - Realizar Venda
   - Terminal Venda
   - Caixa
   - Receber
   - A Pagar
   - Configurações Gerais
   - Suporte
3. **UX/UI:** O sistema deve possuir um modo escuro (Dark Mode) acessível pelo usuário, além de transições de telas fluidas no estilo iOS.

*(Este arquivo será expandido conforme os módulos forem sendo desenvolvidos e especificados)*
